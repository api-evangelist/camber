# Camber

> Camber is a healthcare revenue cycle management (RCM) and medical billing software
> platform purpose-built for specialty care providers — ABA (applied behavior analysis)
> therapy, physical therapy, and ENT and allergy clinics. The platform automates the
> full claims lifecycle: creation and submission, pre-submission scrubbing and
> eligibility verification, payment posting and reconciliation, and denial management
> and prevention. Founded in 2021 (Y Combinator W21) and rebranded from Juniper to
> Camber, the New York company is backed by Craft Ventures, a16z and Y Combinator.

## Agent-relevant status

Camber ships **no public developer program**. As of 2026-08-15 there is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any public
registry, no MCP server, no A2A agent card, and no `/llms.txt` of Camber's own. This
file is generated by API Evangelist from the public profile, not published by Camber.

A production API host does exist — `https://api.camber.health` — but it is an AWS API
Gateway behind Cloudflare that answers HTTP 401 with `WWW-Authenticate: Bearer` on
every path, including `/openapi.json` and every `/.well-known/*` path. Access requires
credentials Camber issues to customers; nothing about the contract is readable
anonymously. Do not attempt to call it without an issued token.

`https://app.camber.health` is the customer web application and is a single-page app:
it returns HTTP 200 with the same HTML shell for every path, so a 200 from that host
is not evidence that a document exists.
